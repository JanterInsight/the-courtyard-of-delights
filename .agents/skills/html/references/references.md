# HTML Modern Development - References

### 1. MDN Web Docs (Mozilla Developer Network)

**HTML - Referencia principal**
- URL: https://developer.mozilla.org/en-US/docs/Web/HTML
- Descripción: Documentación completa y actualizada de HTML5
- Contenido:
  - Referencia de todas las etiquetas HTML
  - Guías de uso y mejores prácticas
  - Ejemplos interactivos
  - Compatibilidad de navegadores

**Elementos HTML específicos:**
- https://developer.mozilla.org/en-US/docs/Web/HTML/Element
- https://developer.mozilla.org/en-US/docs/Web/HTML/Attributes

**Accesibilidad en HTML:**

**Formularios HTML:**

### 2. W3C (World Wide Web Consortium)

**Especificación HTML5:**
- URL: https://www.w3.org/TR/html52/
- Descripción: Especificación oficial de HTML5
- Versión: HTML 5.2 (W3C Recommendation)
- Contenido:
  - Especificación técnica completa
  - Definición de elementos y atributos
  - Reglas de parsing
  - APIs definidas en HTML

**HTML Living Standard:**
- URL: https://html.spec.whatwg.org/
- Descripción: Estándar vivo de HTML mantenido por WHATWG
- Nota: Esta es la versión que siguen los navegadores modernos

**Validación HTML:**
- URL: https://validator.w3.org/
- Descripción: Validador oficial de HTML W3C
- Uso: Verificar que el HTML cumple con estándares

### 3. WCAG (Web Content Accessibility Guidelines)

**WCAG 2.2 Guidelines:**
- URL: https://www.w3.org/WAI/WCAG22/quickref/
- Descripción: Guía rápida de WCAG 2.2
- Contenido:
  - 4 principios: Perceptible, Operable, Comprensible, Robusto
  - 13 pautas directrices
  - Niveles de conformidad A, AA, AAA

**WCAG 2.2 Completo:**
- URL: https://www.w3.org/TR/WCAG22/
- Descripción: Especificación completa de WCAG 2.2
- Versión: W3C Recommendation (2023)

**Understanding WCAG 2.2:**
- URL: https://www.w3.org/WAI/WCAG22/Understanding/
- Descripción: Guía detallada para entender cada criterio de éxito

**Techniques for WCAG 2.2:**
- URL: https://www.w3.org/WAI/WCAG22/Techniques/
- Descripción: Técnicas suficientes y recomendadas para cumplir WCAG
