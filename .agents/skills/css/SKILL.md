# Modern CSS Development

## Purpose

Provides specialized knowledge for developing modern, maintainable, and scalable CSS: advanced CSS3, professional CSS architecture, responsive design, performance, and robust design systems.

## When to Use

- Create CSS styles for a web application
- Implement responsive design with modern CSS (mobile-first)
- Organize styles in a professional and scalable way
- Use CSS Grid, Flexbox, or Container Queries
- Work on Design Systems
- Optimize CSS performance or implement animations and transitions

## Workflow

1. Read `references/instructions.md` and apply its mandatory rules.
2. Consult `references/best-practices.md` during implementation.
3. Verify that the result does not fall into the anti-patterns in `references/common-mistakes.md`.
4. Consult `references/references.md` for official sources when in doubt.
5. Use `examples/responsive-grid.html` as a practical reference.

## Validation

The generated CSS must be maintainable and scalable, with consistent naming conventions, mobile-first responsiveness, optimized performance, accessibility (WCAG 2.2), use of Custom Properties for repeated values, and compatibility with modern browsers.
