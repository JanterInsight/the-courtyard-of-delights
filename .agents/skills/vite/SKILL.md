# Vite Development

## Purpose

Provides specialized knowledge for developing projects with modern Vite: correct configuration, build optimization, environment variables, code splitting, and professional deployment.

## When to Use

- Create a new project with Vite
- Configure vite.config.js, plugins, or import aliases
- Optimize the production build
- Configure environment variables
- Implement code splitting or SSR/SSG
- Deploy a Vite application

## Workflow

1. Read `references/instructions.md` and apply its mandatory rules.
2. Consult `references/best-practices.md` during implementation.
3. Verify that the result does not fall into the anti-patterns in `references/common-mistakes.md`.
4. Consult `references/references.md` for official sources when in doubt.
5. Use `examples/vite-config-example.js` as a practical reference.

## Validation

The generated configuration must be optimized for development and for production builds, correctly use environment variables, implement code splitting, be secure, and follow best practices.
