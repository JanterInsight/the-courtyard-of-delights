# Python Backend Development

## Proposito

Desarrolla aplicaciones backend con Python moderno: frameworks web, manejo de bases de datos y mejores practicas para aplicaciones escalables.

## Cuando usar

- Crear aplicaciones backend con Python
- Trabajar con FastAPI, Django o Flask
- Implementar APIs REST en Python
- Procesar datos, automatizar tareas o hacer web scraping
- Trabajar con analisis de datos o machine learning

## Flujo de trabajo

1. Leer `references/instructions.md` y aplicar sus reglas obligatorias.
2. Consultar `references/best-practices.md` durante la implementacion.
3. Verificar que la implementacion no incurre en los anti-patrones de `references/common-mistakes.md`.
4. Consultar `references/references.md` para fuentes oficiales cuando haya dudas.
5. Usar `examples/fastapi-crud.py` como referencia practica.

## Validacion

El codigo Python generado debe usar type hints, async/await cuando sea apropiado, tener manejo de errores y tests, ser modular, seguir PEP 8 y estar documentado.
