# References

## Purpose

Esta carpeta contiene referencias y documentación adicional para las skills de desarrollo web. Incluye libros, documentación oficial y PDFs de referencia.

## Estructura

```
references/
├── books/          # Libros de referencia
├── documentation/  # Documentación oficial
├── pdfs/           # PDFs de referencia
└── README.md       # Este archivo
```

## Contenido

### books/
- Libros recomendados para cada skill
- Guías de referencia
- Manuales técnicos

### documentation/
- Documentación oficial de tecnologías
- Especificaciones técnicas
- Guías de mejores prácticas

### pdfs/
- PDFs de referencia
- Cheatsheets
- Documentos técnicos

## Uso

Las referencias en esta carpeta complementan las skills individuales. Cada skill tiene su propio archivo `references.md` con las fuentes más relevantes.

## Skills Relacionadas

- **Frontend:** HTML, CSS, JavaScript, React, TypeScript, Vite, Accessibility
- **Backend:** Node.js, Express, Supabase, Python, Database Design, API Design, Web Security
- **Arquitectura:** Web Architecture

## Nota

Siempre verificar la documentación oficial de cada tecnología para obtener la información más actualizada.
