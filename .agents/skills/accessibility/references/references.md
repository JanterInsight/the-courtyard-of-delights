# Web Accessibility - References

## Fuentes Oficiales y Documentación

### 1. WCAG (Web Content Accessibility Guidelines)

**WCAG 2.2:**
- URL: https://www.w3.org/WAI/WCAG22/quickref/
- Descripción: Estándar internacional de accesibilidad web
- Contenido:
  - 4 principios: Perceivable, Operable, Understandable, Robust
  - 13 guidelines
  - 86 success criteria
  - 3 niveles de conformidad: A, AA, AAA

**WCAG 2.2 Overview:**
- URL: https://www.w3.org/WAI/WCAG22/
- Descripción: Visión general de WCAG 2.2

**WCAG 2.2 Techniques:**
- URL: https://www.w3.org/WAI/WCAG22/Techniques/
- Descripción: Técnicas para cumplir con WCAG

## Notas sobre las Fuentes

### Prioridad de Fuentes

1. **WCAG 2.2** - Estándar oficial internacional
2. **ARIA Practices** - Guía oficial de ARIA
3. **MDN Accessibility** - Documentación técnica
4. **WebAIM** - Recursos prácticos
5. **axe DevTools** - Herramienta de testing

### Niveles de Conformidad WCAG

- **Nivel A:** Mínimo accesibilidad
- **Nivel AA:** Estándar recomendado (legal en muchos países)
- **Nivel AAA:** Máxima accesibilidad

### Actualización de Conocimiento

- WCAG 2.2 es el estándar actual (2023)
- WCAG 3.0 en desarrollo
- Mantenerse al día con:
  - W3C WAI updates
  - WebAIM articles
  - A11y Project
  - axe blog

### Contribuir

- W3C WAI: https://www.w3.org/WAI/
- WebAIM: https://webaim.org/
