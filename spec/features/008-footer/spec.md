# Feature: Footer

## Descripción

Implementar el footer del sitio con información de copyright y créditos, manteniendo el diseño coherente con la identidad de marca.

## Requisitos Funcionales

### RF-001: Contenido
- Copyright: "© 2026 - El Patio de las Delicias - Helados Artesanales"
- Texto: "Hecho con ❤️ para nuestra comunidad"
- Diseño centrado
- Colores de marca

### RF-002: Diseño
- Fondo con color de marca
- Tipografía legible
- Espaciado adecuado
- Alineación centrada
- Responsive

## Requisitos No Funcionales

### RNF-001: Accesibilidad
- Estructura semántica con footer
- role="contentinfo"
- Contraste adecuado

### RNF-002: Rendimiento
- Sin dependencias externas
- CSS puro

### RNF-003: Responsive
- Mobile-first design
- Padding adaptativo

## Criterios de Aceptación

- [ ] Footer visible al final de la página
- [ ] Copyright mostrado correctamente
- [ ] Corazón emoji visible
- [ ] Diseño centrado
- [ ] Colores de marca aplicados
- [ ] Responsive en móvil y desktop
- [ ] Accesibilidad implementada
