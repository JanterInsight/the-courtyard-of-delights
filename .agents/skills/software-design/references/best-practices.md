# Mejores Prácticas de Software Design

## Principios
- Aplicar SOLID en todo el código
- Usar inyección de dependencias
- Favorecer composición sobre herencia
- Programar contra interfaces
- Mantener bajo acoplamiento

## Patrones
- Repository para acceso a datos
- Service layer para lógica de negocio
- Factory para creación de objetos
- Strategy para algoritmos intercambiables
- Observer para eventos

## Arquitectura
- Clean Architecture para separación de concerns
- Feature-based para escalabilidad
- Capas claras: presentation, domain, data
- Dependencias hacia adentro

## Calidad
- Código legible y mantenible
- Tests unitarios para lógica de negocio
- Documentación de decisiones (ADR)
- Refactoring continuo
- Code review regular
