# Vite Development

## Proposito

Proporciona conocimiento especializado para desarrollar proyectos con Vite moderno: configuracion correcta, optimizacion de builds, variables de entorno, code splitting y despliegue profesional.

## Cuando usar

- Crear un nuevo proyecto con Vite
- Configurar vite.config.js, plugins o aliases de importacion
- Optimizar el build de produccion
- Configurar variables de entorno
- Implementar code splitting o SSR/SSG
- Desplegar una aplicacion Vite

## Flujo de trabajo

1. Leer `references/instructions.md` y aplicar sus reglas obligatorias.
2. Consultar `references/best-practices.md` durante la implementacion.
3. Verificar que el resultado no incurre en los anti-patrones de `references/common-mistakes.md`.
4. Consultar `references/references.md` para fuentes oficiales cuando haya dudas.
5. Usar `examples/vite-config-example.js` como referencia practica.

## Validacion

La configuracion generada debe estar optimizada para desarrollo y para build de produccion, usar variables de entorno correctamente, implementar code splitting, ser segura y seguir mejores practicas.
