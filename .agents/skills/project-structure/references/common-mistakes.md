# Errores Comunes de Project Structure

## ❌ Organización
- Estructura por tipos en lugar de features
- Carpetas demasiado profundas
- Código duplicado entre features
- Dependencias circulares
- Mezclar UI con lógica

## ❌ Imports
- Rutas relativas largas (../../../../)
- Imports desordenados
- Barrel files innecesarios
- Dependencias circulares

## ❌ Escalabilidad
- Features acoplados entre sí
- Compartir código sin pasar por shared/
- No documentar la estructura
- Estructura que no escala con el proyecto

## ❌ Convenciones
- Nombres inconsistentes
- PascalCase para archivos
- Mezclar convenciones de naming
- No usar index files
