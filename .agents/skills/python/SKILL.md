# Python Backend Development

## Purpose

Develop backend applications with modern Python: web frameworks, database handling, and best practices for scalable applications.

## When to Use

- Create backend applications with Python
- Work with FastAPI, Django, or Flask
- Implement REST APIs in Python
- Process data, automate tasks, or perform web scraping
- Work with data analysis or machine learning

## Workflow

1. Read `references/instructions.md` and apply its mandatory rules.
2. Consult `references/best-practices.md` during implementation.
3. Verify that the implementation does not fall into the anti-patterns from `references/common-mistakes.md`.
4. Consult `references/references.md` for official sources when in doubt.
5. Use `examples/fastapi-crud.py` as a practical reference.

## Validation

The generated Python code must use type hints, async/await when appropriate, have error handling and tests, be modular, follow PEP 8, and be documented.
