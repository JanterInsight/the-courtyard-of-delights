# Errores Comunes de Code Review

## ❌ Errores de Proceso
- Revisar PRs demasiado grandes
- Aprobar sin entender el código
- Solo revisar estilo/formatting
- Ignorar problemas de seguridad
- No verificar tests

## ❌ Errores de Feedback
- Feedback vago sin ejemplos
- Ser demasiado crítico sin contexto
- No priorizar problemas por severidad
- Ignorar buen código
- No explicar el porqué

## ❌ Errores de Seguridad
- No verificar validación de entradas
- Ignorar XSS y SQL injection
- No revisar auth/authorization
- Exponer secrets en código
- No verificar RLS

## ❌ Errores de Calidad
- No verificar principios SOLID
- Ignorar código duplicado
- No evaluar complejidad
- No verificar manejo de errores
- Aprobar sin tests
