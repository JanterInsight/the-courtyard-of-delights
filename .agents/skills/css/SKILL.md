# Modern CSS Development

## Propósito

Proporciona conocimiento especializado para desarrollar CSS moderno, mantenible y escalable: CSS3 avanzado, arquitectura CSS profesional, diseño responsive, rendimiento y sistemas de diseño robustos.

## Cuándo usar

- Crear estilos CSS para una aplicación web
- Implementar diseño responsive con CSS moderno (mobile-first)
- Organizar estilos de manera profesional y escalable
- Utilizar CSS Grid, Flexbox o Container Queries
- Trabajar en sistemas de diseño (Design Systems)
- Optimizar el rendimiento de CSS o implementar animaciones y transiciones

## Flujo de trabajo

1. Leer `references/instructions.md` y aplicar sus reglas obligatorias.
2. Consultar `references/best-practices.md` durante la implementación.
3. Verificar que el resultado no incurre en los anti-patrones de `references/common-mistakes.md`.
4. Consultar `references/references.md` para fuentes oficiales cuando haya dudas.
5. Usar `examples/responsive-grid.html` como referencia práctica.

## Validación

El CSS generado debe ser mantenible y escalable, con nomenclatura consistente, responsive mobile-first, rendimiento optimizado, accesible (WCAG 2.2), uso de Custom Properties para valores repetitivos y compatibilidad con navegadores modernos.
